COFFEE & BREAD FOOD PUZZLE

HOW TO RUN
1. Keep index.html, style.css, script.js, and the images folder together.
2. Double-click index.html to open the game in a web browser.
3. Choose a dish and move tiles by selecting a piece beside the empty space.

PROJECT FILES
- index.html: page structure and text
- style.css: Coffee & Bread branding and responsive layout
- script.js: puzzle selection, guaranteed-solvable shuffle, moves, and win screen
- images/: logo and the three puzzle photos

FUTURE WEBSITE INTEGRATION
The project is a standalone web page. When the team's website is ready, this
folder can be hosted as a /puzzle page or linked from the website and QR code.


FUTURE
